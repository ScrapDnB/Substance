# Timecode font

Chakra Petch Bold is the same unmodified font bundled with Dubbing Manager's
teleprompter. Substance registers it locally with Qt; no system installation or
runtime download is needed.

Source: https://github.com/google/fonts/tree/main/ofl/chakrapetch
License: SIL Open Font License 1.1; see `ChakraPetch-OFL.txt`.

The font and its license are included by both the Python package data rules and
the PyInstaller resources directory.
