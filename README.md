# Substance · v0.9.2-beta

Редактор ASS для создания субтитров, тайминга и перевода. Предварительная рабочая версия для дальнейших итераций.

## Запуск на Mac

Готовое приложение находится в `dist/Substance.app`. Откройте его двойным щелчком или выполните:

```sh
open dist/Substance.app
```

Эта локальная сборка предназначена для **Apple Silicon, macOS 15 и новее**. Python, Qt, FFmpeg, ffprobe, libass и словари входят в пакет. Минимальные версии всех встроенных Mach-O проверяются сборщиком; запуск непосредственно на macOS 15 ещё предстоит проверить. Сборка имеет локальную подпись; Developer ID и notarization не выполнялись.

На macOS панель инструментов — настоящий AppKit `NSToolbar` с SF Symbols, системным переключателем режимов, настройкой состава кнопок и меню переполнения. На macOS 26+ панель получает системное оформление Liquid Glass, а боковая навигация использует `NSGlassEffectView` с нативными фильтрами, выбором персонажа и подключением медиа внутри `contentView`. На macOS 15 сохраняется стандартное оформление AppKit и обычная боковая панель. Текст, таблица и медиа используют непрозрачные семантические поверхности. Windows использует Qt FluentWinUI3, системную палитру и диалоги. Подсказки используют AppKit на macOS и системный tooltip-контрол Windows. Windows-пакет собирается на Windows; его запуск на реальной Windows в этой итерации ещё не проверен.

## Рабочие возможности

- Сравнение файлов и выборочный перенос полей, тайминг готового сценария, обработка интервалов, профили проверок и отчёты, пакетная обработка серий, импорт PGS/VobSub и реальные времена кадров VFR. Меню распределено по задачам: «Проверка», «Медиа», «Тайминг», «Реплики», «Проект». [Новые рабочие процессы](docs/file-workflows.md).

- Словарь и перевод выделенного текста с Microsoft Azure, DeepL или LibreTranslate. Локальные словари Викисловаря, значения, примеры и перевод фраз; все параметры и инструкции — в «Настройки → Словарь и перевод». [Подключение и использование](docs/language-assistance.md).
- Поиск и распознавание хардсаба из видео с выбором области кадра, проверкой текста и таймкодов, импортом для перевода и общей отменой. [Как пользоваться и настроить OCR](docs/hardsub.md).
- Инструменты доводки с кнопками на верхней панели: проверка и исправление с предпросмотром, баланс строк / разделение / объединение, уточнение тайминга по локально распознанной речи и поиск смен планов. Третий вид аудиопанели «Дорожки» показывает редактируемые полупрозрачные блоки поверх волны: одиночные фразы занимают всю высоту, а группы пересечений делятся на локальные ряды без ограничения их числа. Выделение не сдвигает аудиовид. [Описание и ограничения](docs/editor-tools.md).
- «Тайминг → Сопоставить по смыслу и разбить»: локальное сопоставление перевода с иноязычной речью в двух режимах — быстрый «По предложениям» и «Точный» с разбиением по звучащим словам. Определение роли единственной колонки, предпросмотр оригинала/перевода и общая отмена. [Как пользоваться](docs/semantic-timing.md).

- Локальное распознавание речи: «Медиа → Создать субтитры из аудио…» или иконка субтитров справа от видео на верхней панели. Скачиваемые модели Whisper, выделение речи Silero VAD, границы слов и фраз, настройки времени чтения, языка, дорожки и диапазона. Готовые реплики появляются в главной таблице без смены выделения. Можно редактировать их во время распознавания, остановить задачу и сохранить результат. «Отменить распознавание» удаляет нетронутые машинные строки, сохраняя ручные правки. [Подробности](docs/transcription.md).
- Создание ASS с нуля; импорт ASS/SSA, SRT, WebVTT и текстового сценария. Импорт встроенной текстовой дорожки из видео.
- Четыре раздела: «Подготовка», «Тайминг», «Перевод», «Пост». В подготовке и посте слева находится колонка инструментов, справа — настройки, предпросмотр и действия выбранного инструмента. Тайминг и перевод сохраняют привычный редактор с оригиналом рядом, фильтрами и словарём. [Как пользоваться разделами](docs/workflow-sections.md).
- Панели имеют отдельные заголовки и группы инструментов. Проверки и заметки раскрываются у текущей реплики; их счётчики и применение остаются под редактором при прокрутке. Раскладки двух режимов настраиваются независимо.
- Кнопки B / I / U / S задают жирный, курсив, подчёркивание и зачёркивание выделенному тексту или новому вводу с курсора. Повторное нажатие снимает оформление. Кнопки включают визуальный показ; режим кодов можно вернуть галочкой «Показывать оформление». При оформлении до конца реплики завершающий сброс не добавляется. Горячие клавиши: Ctrl+B / I / U (⌘ на macOS), доступны для переназначения в настройках. Каждое изменение можно отменить; ASS-теги за пределами выделения сохраняют своё действие.
- Независимые галочки «Показывать оформление» у оригинала и перевода скрывают коды тегов и показывают жирный, курсив, подчёркивание и зачёркивание прямо в соответствующем поле. Переключение не меняет текст; скопированный текст сохраняет теги. Полное оформление ASS отображается в видеопредпросмотре.
- «Правка → Учитывать стили ASS» включает жирный, курсив, подчёркивание и зачёркивание из стилей файла. По умолчанию выключено: используются теги строки и ручное оформление. Выбор действует в редакторе, видеопредпросмотре и итоговом ASS; исходные стили остаются в проекте. Экспорт оригинала сохраняет исходные стили.
- «Правка → Сохранять оформление» автоматически переносит ASS-оформление всей исходной реплики при вводе перевода. Если оформлен только фрагмент оригинала, перенос не выполняется. Вручную заданные теги перевода имеют приоритет. Настройка и обе галочки отображения запоминаются; автоперенос поддерживает отмену.
- «Правка → Удалить ASS-теги…»: выбор найденных типов тегов с количеством вхождений и реплик, удаление из итогового текста всего документа одной отменяемой операцией, включая вложенные команды `\t(...)`. Оригинал сохраняется.
- После сохранения или экспорта ASS появляется предупреждение: ASS содержит одну версию текста; оригинал и перевод вместе хранятся в `.substance`.
- В проектах `.substance`: заметки к репликам, предложения правок с подсветкой различий, применением, отклонением и историей.
- Карточки персонажей: имена и алиасы, описание, особенности речи, заметки, галерея и назначение репликам. Портрет можно загрузить или захватить и обрезать из открытого видео.
- Видео и аудио, точный предпросмотр через libass, выбор аудиодорожки, скорость и громкость, воспроизведение интервала и повтор.
- Волна и спектр, масштабирование, прокрутка, перетаскивание границ и выделение интервала; привязка к соседним границам и ключевым кадрам.
- Внизу аудиопанели рядом с горизонтальным масштабом: громкость воспроизведения и высота волны (25–800%) либо контраст спектра (25–300%) для выбранного вида. Высота и контраст сохраняются на устройстве между запусками; высота волны не меняет громкость звука.
- Добавление, удаление, дублирование, разделение по курсору и объединение; операции над выделенными строками, перенос через буфер обмена, отмена и повтор.
- Наглядный сдвиг времени: «раньше / позже», ползунок, точный ввод в миллисекундах, шаги по кадрам и сравнение «сейчас / после». Точечная синхронизация по нескольким опорным репликам исправляет постоянное смещение и расхождение скорости. Обе команды доступны в «Тайминг» и на панели; проверки находятся в «Проверке», работа со звуком и видео — в «Медиа». [Как пользоваться](docs/editor-tools.md#ручная-синхронизация).
- Поиск и замена с регулярными выражениями; локальная проверка орфографии на русском и английском.
- Контроль скорости чтения, длины и количества строк, пустых реплик, нулевых интервалов и соседних пересечений. Пороги доступны в настройках.
- Экспорт ASS, SRT, VTT, TXT, включая исходный текст. Автосохранение каждые 15 секунд и восстановление незавершённого ввода после сбоя.
- Нативные меню и диалоги, изменяемые размеры панелей, светлая/тёмная/системная тема, короткие анимации и системный Reduce Motion.

Инструменты оформления, караоке, автоматизация Lua и открытие проектов Dubbing Manager не входят в текущую реализацию. Имеющиеся стили, теги и вложения ASS сохраняются; точный внешний вид зависит также от установленных шрифтов. Текстовый импорт получает временные интервалы-заглушки и замечание «Тайминг ещё не задан». Обратные интервалы и повреждённые события сохраняются как исходные строки с замечаниями импорта. После чтения индекса в «Медиа → Точные времена кадров» шаг по кадрам и округление используют реальные временные метки, включая VFR. До чтения используется выбранная сетка FPS.

## Сохранение оригинала и перевода

**Сохранить как → `.substance`** сохраняет документ, оригиналы, перевод, заметки, предложения правок, карточки персонажей с изображениями, настройки проверок, историю происхождения строк и ссылку на медиа в одном JSON-файле. Видео и аудио остаются отдельными файлами; путь можно переназначить через «Открыть медиа».

**Сохранить → `.ass`** создаёт обычный ASS для проигрывателей и соседний файл `имя.ass.substance` с данными перевода. Храните и переносите их вместе, чтобы повторно открыть оригинал и перевод. Если ASS изменён внешним редактором, Substance проверит хеш и не применит устаревшие данные перевода.

**Экспорт** создаёт выбранный конечный формат без служебного файла. В SRT/VTT/TXT оформление ASS снимается. Для импортированных субтитров оригинал сохраняется неизменным. При создании с нуля исходный текст обновляется, пока у реплики нет перевода или связанных фрагментов.

## Заметки, правки и персонажи

Эти функции доступны в самостоятельном проекте `.substance`. При первом
действии над импортированным ASS/SRT приложение предлагает сохранить такой проект.
Файл `имя.ass.substance`, автоматически сопровождающий ASS, хранит только данные
перевода и происхождения; заметки, карточки и изображения в него не записываются.

Под редактором доступны «+ Заметка», «Предложить правку» и «Заметки и правки».
В общем списке можно переключить текущую реплику/все записи и включить историю.
Заметки редактируются, удаляются и отмечаются решёнными. Предложение хранит
исходный и предлагаемый варианты отдельно от рабочего текста. Применение меняет
текст и состояние предложения одной операцией отмены. Если текст, поле перевода
или структура реплики изменились, предложение сначала нужно пересмотреть.
Разделение/объединение сохраняет связи заметок; записи удалённых реплик остаются
в архиве с фрагментом текста. Оригинал перевода остаётся неизменным.

Откройте «Персонажи» в боковой панели или «Карточка» под редактором. Можно
редактировать имя, алиасы, имя в экспорте, описание, особенности речи и заметки,
назначать карточку выделенным репликам и переходить к репликам из карточки.
Переименование сохраняет связи по ID. Используемая карточка удаляется после
снятия назначений. Карточку можно держать открытой во время работы.

«Портрет» под видео или «Из видео…» в карточке фиксирует декодированный кадр.
После перемотки захват ждёт обновления кадра. Перемещайте рамку и её углы;
доступны свободные пропорции, квадрат и портрет 3:4. Сохраните существующему
или новому персонажу, выбрав основной портрет либо дополнительное изображение.
«Из файла…» принимает PNG/JPEG/WebP/BMP. Для сохранённых изображений доступны
повторная обрезка, смена основного, удаление и переход к кадру видео.

Изображения встроены в проект; видео остаётся отдельным файлом. Исходник
обрезки ограничен 2048 пикселями по большей стороне, портрет — 768 пикселями.
Повторная обрезка использует сохранённый исходник и не требует видео.
Одинаковые изображения хранятся один раз. Максимальный размер проекта — 100 МБ.

В «Файл → Настройки документа…» отдельно включаются проверки длины строки,
скорости чтения, количества строк и пересечений. Отключённые проверки
не добавляют предупреждения; заметки и предложения остаются доступны.

В окне «Настройки» есть поиск и отдельные разделы оформления, размеров,
раскладки тайминга и перевода, проверок и импорта, горячих клавиш и языковой помощи.
Внешний вид применяется сразу и сохраняется на этом компьютере:

- Масштаб подписей и элементов, шрифт и размеры текста таблицы, оригинала
  и перевода, высота строк, перенос длинных реплик, фон и разделители строк,
  ширина боковой панели.
- Отдельные шрифт и размер таймкода (10–28 px) с живым образцом цифр:
  Menlo/Consolas с перечёркнутым нулём, Verdana и Courier New с обычным,
  Chakra Petch Bold и системный вариант «как у текста», следующий за выбором
  текстового шрифта. Chakra Petch встроен в приложение и не требует установки.
  Выбор общий для таблицы, полей начала и конца реплики, времени плеера
  и аудиошкалы; сохраняется между запусками.
- Системная, светлая или тёмная тема, готовые цветовые акценты и выбор
  цветов выделения, аудиоволны и текстовых полей. Цвета фона и текста полей
  сохраняются отдельно для светлой и тёмной темы.
- Независимые раскладки «Тайминг» и «Перевод» с живой схемой: сторона и
  размер видео, видимость и высота аудио, порядок таблицы и редактора,
  положение оригинала и перевода, контекст. Размеры, изменённые перетягиванием
  разделителей, также запоминаются. У каждой раскладки свой сброс.

Эти параметры не меняют ASS-стили, экспорт, текст документа или историю
отмены. При перестановке панелей незавершённый текст остаётся в редакторе.
В «Проверках и импорте» задаются проверки и пороги по умолчанию для новых
документов и впервые открытых субтитров без собственных настроек. Изменение
этих значений не затрагивает текущий документ.

«Файл → Настройки документа…» открывает отдельное окно с частотой кадров,
кодировкой ASS, включёнными проверками и их порогами. «Применить» сохраняет
изменения одной отменяемой операцией; «Отмена» оставляет документ без изменений.
Проверки документа сохраняются в `.substance` или в сопутствующем `.ass.substance`.

Ширину колонок таблицы можно менять перетаскиванием правой границы заголовка.
Двойной щелчок по границе возвращает автоматическую ширину. Размеры
запоминаются на компьютере отдельно для тайминга и перевода. Правый щелчок
по заголовку таблицы открывает выбор отображаемых колонок; этот выбор тоже
сохраняется отдельно для двух режимов. «Показать все колонки» возвращает
скрытые колонки, сохраняя заданную ширину. Последняя колонка
с индикаторами не имеет названия и остаётся видимой при наличии заметок или
предложений, даже когда все проверки отключены. При необходимости её можно
скрыть вручную через меню колонок.

Изменения поддерживают отмену и повтор, автосохранение и восстановление,
включая незавершённый ввод в карточке. Экспорт включает текущий текст и имя
персонажа для экспорта. «Сохранить как → ASS» из проекта выполняет экспорт,
сохраняя рабочий проект и его служебные данные.

## Репозиторий

Git-репозиторий использует ветку `main`. Исходники, документация,
тесты и GitHub Actions включены; сборки, окружения, проекты, медиа и локальные

[docs/builds.md](docs/builds.md). Инструкции для разработки —
[CONTRIBUTING.md](CONTRIBUTING.md).

## Горячие клавиши

На macOS вместо Ctrl используется ⌘. Комбинации показываются в меню, подсказках и настройках, где их можно переназначить.

| Действие | Windows | macOS |
|---|---|---|
| Открыть / сохранить | Ctrl+O / Ctrl+S | ⌘O / ⌘S |
| Экспорт | Ctrl+E | ⌘E |
| Применить; в переводе — следующая реплика | Ctrl+Enter | ⌘Enter |
| Добавить реплику | Ctrl+Shift+Enter | ⌘⇧Enter |
| Предыдущая / следующая | Alt+↑ / Alt+↓ | ⌥↑ / ⌥↓ |
| Дублировать / разделить / объединить | Ctrl+D / Ctrl+Shift+D / Ctrl+J | ⌘D / ⌘⇧D / ⌘J |
| Отменить / повторить | Ctrl+Z / Ctrl+Y | ⌘Z / ⌘⇧Z |
| Воспроизвести / пауза | Ctrl+Space | ⌘⇧Space |
| Воспроизвести реплику | Alt+Space | ⌥Space |
| Начало / конец по текущему кадру | Ctrl+1 / Ctrl+2 | ⌘1 / ⌘2 |
| Сдвинуть начало раньше / позже | Ctrl+← / Ctrl+→ | ⌃← / ⌃→ |
| Сдвинуть конец раньше / позже | Ctrl+Alt+← / Ctrl+Alt+→ | ⌘← / ⌘→ |
| Сдвинуть всю реплику раньше / позже | Alt+← / Alt+→ | ⌥← / ⌥→ |
| Предыдущий / следующий кадр | Alt+, / Alt+. | ⌥, / ⌥. |
| Сдвиг времени | Ctrl+Shift+T | ⌘⇧T |
| Найти / заменить | Ctrl+F / Ctrl+H | ⌘F / ⌘H |
| Копировать / вставить реплики | Ctrl+Shift+C / Ctrl+Shift+V | ⌘⇧C / ⌘⇧V |
| Удалить реплики | Ctrl+Shift+Backspace | ⌘⇧Backspace |

Сдвиг границ меняет текущую реплику с шагом 100 мс; Shift включает точный шаг
10 мс. Оба шага (1–5000 мс) и все сочетания сдвига настраиваются в
«Настройки → Тайминг». Команды работают также из текстового поля и полей времени,
поддерживают удержание клавиши и отмену. У нулевой отметки и противоположной
границы сдвиг останавливается; перенос всей реплики сохраняет её длительность.
В открытых диалогах и разделах подготовки/завершения эти сочетания не меняют тайминг.

Пробел также включает воспроизведение, когда фокус вне поля ввода. Обычные копирование/вставка работают с текстом. В таблице Shift выделяет диапазон, Ctrl/⌘ — отдельные строки. На волне Shift+перетаскивание задаёт интервал, правая кнопка прокручивает. На тачпаде прокрутка двумя пальцами по горизонтали или вертикали плавно перемещает аудио с системной инерцией и направлением прокрутки. Щипок и Ctrl/⌘+прокрутка (либо колесо мыши) меняют масштаб вокруг указателя. Жесты работают на волне, спектре и поверх реплик в режиме дорожек. Системные комбинации, например Spotlight, можно заменить в настройках.

## Запуск из исходников

```sh
python3 -m venv .venv
.venv/bin/python -m pip install ./vendor/dubbing-online-client
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python run.py
```

На Windows используйте `.venv\Scripts\python.exe`. Для точного ASS-предпросмотра из исходников установите libass; на Mac — `brew install libass ffmpeg`. В сборке необходимые библиотеки уже включены. PyObjC устанавливается только на macOS. Отдельная компиляция Swift-моста не нужна.

### QML Live Preview на macOS

Обычный запуск и сборка используют PySide6 / Qt 6.10.2. Предпросмотр работает в
отдельном окружении `.venv-qt612` на Qt 6.12.0. Проверенные бинарные Python-биндинги
PySide6 6.12.0 требуют macOS 26+, хотя сами Qt frameworks требуют только 14.4.
Поэтому версия релизного Qt пока сохранена: минимум готового пакета остаётся macOS 15.

Для предпросмотра установите через Qt
Maintenance Tool компонент **Agentic Development Tools → QML Live Preview**.
По умолчанию сервер ожидается в `~/Qt/6.12.0/macos/bin/QmlPreviewMcpServer`.

Один раз подготовьте отдельное окружение:

```sh
.venv/bin/python scripts/setup_qml_preview.py
```

После установки зависимостей дважды нажмите **QML Preview.command** в корне
проекта или выполните:

```sh
.venv-qt612/bin/python scripts/qml_preview.py
```

Откроется Substance. Сохраняйте изменения в `substance/qml/*.qml`: поддерживаемые
изменения применяются в работающем окне без перезапуска. Изменения Python-кода,
регистрации типов и некоторые изменения структуры QML требуют перезапуска.
Это предпросмотр изменений кода; элементы мышью редактируются в Qt Design Studio.

Предпросмотр использует отдельные настройки и восстановление в
`local/qml-preview-state`; журнал находится в `local/qml-preview.log`.
Закрытие Substance или Ctrl+C завершает предпросмотр. Для другого расположения
сервера добавьте `--server /полный/путь/QmlPreviewMcpServer`.
Файл проекта можно передать после `--`:

```sh
.venv-qt612/bin/python scripts/qml_preview.py -- /полный/путь/субтитры.ass
.venv-qt612/bin/python scripts/qml_preview.py --check
```

На macOS сервер получает библиотеки из того же PySide6, что и приложение:
отдельная установка всего Qt SDK для этого способа не обязательна.
QML debugging включается только явным `--qml-preview` при запуске из исходников;
в готовой сборке этот режим отключён. Минимум готового macOS-пакета остаётся 15.0.
Результаты проверки и ограничение бинарных PySide6 6.12:
[docs/qt612-preview-verification.md](docs/qt612-preview-verification.md).

```sh
.venv/bin/python scripts/test.py
.venv/bin/python scripts/build.py
```

Собирать приложение нужно на целевой ОС и архитектуре. GitHub Actions в `.github/workflows/build.yml` автоматически готовит отдельные пакеты macOS (Apple Silicon) и Windows (x64) при обновлении `main`. Теги `v*` дополнительно публикуют предварительный GitHub Release с архивами обеих платформ и контрольными суммами; также доступны проверки pull request и ручной запуск. Общий клиент DubbingManager устанавливается из `vendor/dubbing-online-client`, поэтому соседний репозиторий и приватный индекс пакетов не нужны. Для проверки приватных примеров можно задать `DUBBING_MANAGER_TEST_FILES`; при их отсутствии соответствующий тест пропускается. Оригинальные тестовые файлы не изменяются и не включаются в дистрибутив.

Для сборки Mac используйте Python с минимальной версией macOS не выше 15. Системные библиотеки Homebrew могут требовать версию ОС, на которой они собраны. Локальный пакет использует совместимые библиотеки conda-forge из `build/portable`; CI выполняет такую же установку. Можно задать свои пути `SUBSTANCE_LIBASS` и `SUBSTANCE_FFPROBE`. Сборщик отклоняет пакет, если какая-либо встроенная библиотека требует macOS новее заявленной в `Info.plist`.

Архитектура и будущая совместимость: [docs/compatibility.md](docs/compatibility.md). Проверки текущей итерации: [docs/verification.md](docs/verification.md). Концепты интерфейса: [design/concepts](design/concepts).

Онлайн-серии DubbingManager: [подключение и ограничения](docs/online.md).

### Автопортреты из видео

На верхней панели доступна кнопка с портретом «Автопортреты из видео…». В карточках персонажей — «Автопортреты…», в онлайн-глоссарии — «Автозаполнить портреты…», в видео — «Авто…».
