# Подготовка и проверка субтитров

Меню сгруппировано по задачам. «Файл» содержит сравнение и обработку нескольких
файлов; «Правка» — перенос отдельных полей; «Реплики» — разбиение и переносы;
«Тайминг» — синхронизацию, обработку интервалов и тайминг сценария.
В «Проверке» находятся проверки, профили и отчёты. В «Медиа» перенесены
подключение видео/аудио, импорт дорожек, распознавание, поиск склеек и чтение
времён кадров. «Проект» объединяет персонажей, портреты, заметки и предложения.

## Сравнить с другим файлом

Откройте «Файл → Сравнить с другим файлом», выберите второй файл и поля,
которые нужно перенести. Слева показаны пары реплик и типы различий,
справа — текущая версия, другой файл и результат выбранных полей.
Изменённые слова подчёркнуты. Отметьте нужные пары и примените изменения.
По результатам можно двигаться клавишами ↑/↓; пробел отмечает или снимает
галочку у текущей строки. Текущая строка подсвечивается и остаётся видимой
при прокрутке. Навигация учитывает фильтр «Только различия».
В поле «Тип различий» можно отдельно показать изменения текста, времени,
персонажа, стиля/слоя/отступов, добавленные или удалённые реплики.
Счётчик слева показывает количество видимых строк; отметки скрытых строк
сохраняются и входят в общий счётчик применения.

Строки сопоставляются по содержимому и времени. Отсутствующие строки показаны
отдельно. Кнопка «Исправить сопоставление» позволяет указать соответствующую
пару номеров. Добавления и удаления включаются отдельной галочкой.
Если в основном редакторе изменён документ, обновите сравнение.

## Вставить отдельные поля

Выделите реплики, затем откройте «Правка → Вставить выбранные данные».
Источником служат скопированные реплики или отдельный файл.
Реплики соответствуют друг другу по порядку выделения. При разном количестве
лишние строки не добавляются; окно показывает предупреждение.
Можно перенести текст, время, персонажа, стиль/слой/отступы ASS.
Встроенные теги внутри текста переносятся вместе с текстом.
Оригинал, идентификаторы и исходное происхождение существующих реплик сохраняются.
Изменения отменяются одной командой. При конфликте названий импортированные
стили получают отдельное имя, сохраняя стили остальных реплик.

## Обработать интервалы

«Тайминг → Обработать интервалы» объединяет отступы до/после речи,
закрытие коротких пауз, сокращение пересечений одного персонажа,
привязку к склейкам и округление к кадрам. Можно ограничить область выделением,
персонажами и стилями и сохранить параметры под своим названием.
Настройки длиннее доступного места прокручиваются внутри своего блока;
результат и кнопка применения остаются видны.

По умолчанию одновременная речь сохраняет своё время. Сокращение пересечений
включается явно. Анимированные события требуют ручного тайминга.
Привязка, которая создала бы новое пересечение или слишком короткую реплику,
показывается как замечание без автоматического исправления.

## Тайминг готового сценария

Откройте «Тайминг → Тайминг готового сценария». Выберите существующие реплики
либо добавьте TXT: одна реплика на строку; допустимо `Персонаж: текст`.
Подключите аудио/видео, выберите дорожку, звучащий текст и диапазон его звучания.
Скачайте модель выбранного языка, затем нажмите «Найти время реплик».

Доступны русский (303 МиБ) и английский (91 МиБ). Модели работают локально,
загрузка проверяется по размеру и SHA-256. После скачивания сеть не нужна.
Текст должен соответствовать речи; числа требуется записывать словами.
Перевод можно выравнивать только с записью, в которой звучит этот перевод.

Используется CTC forced alignment заданных токенов с ONNX wav2vec2, без
подмены сценария распознанным текстом. Длинные последовательности разделяются
по акустически подтверждённым опорным фрагментам. Если надёжных опорных слов
нет, приложение предлагает уменьшить диапазон. Полученные интервалы изначально
не выбраны: прослушайте их, отметьте подходящие и примените одной операцией.

## Профили и отчёты

В «Проверка → Проверить и исправить» доступны текущие настройки документа,
обычный профиль и сохранённые профили пользователя. Параметры включают скорость
чтения, длину и количество строк, длительность, промежутки и пересечения.
Именованные профили сохраняются на устройстве. Их можно использовать в пакетной
обработке. Кнопка «Сохранить отчёт» записывает текущую проверку в HTML или CSV.
Это настраиваемые редакторские проверки, без заявления о сертификации под
требования конкретного сервиса.

## Обработать несколько файлов

«Файл → Обработать несколько файлов»: выберите исходники, формат результата,
профиль проверки, общий сдвиг и последовательные буквальные замены вида
`найти → заменить` (одна на строку). Подготовьте результат, проверьте примеры
и отметьте файлы для записи. Выберите папку и нажмите «Сохранить новые файлы».

Создаётся новая подпапка `Substance-дата-время`, содержащая результаты,
отчёты HTML/CSV и журнал JSON. Исходники не перезаписываются. Файл, изменившийся
после предпросмотра, пропускается с объяснением. При остановке уже записанные
результаты перечисляются в журнале. ASS содержит итоговый текст и оформление;
SRT/VTT/TXT — итоговый текст без оформления; `.substance` — полный проект.

## Графические субтитры

«Медиа → Распознать PGS / VobSub»: выберите `.sup`, `.idx` рядом с `.sub`
или Matroska с графической дорожкой. Выберите дорожку и язык OCR.
Изображения декодируются отдельно от основного процесса; распознавание
использует Apple Vision либо настроенный Tesseract.

Выберите реплику слева и сверьте текст с изображением справа. Исправьте текст
и время, сохраните исправление. Отмеченные реплики добавляются с общей отменой.
В режиме подготовки для перевода распознанный текст становится оригиналом,
а поле перевода остаётся пустым. Изображения для проверки не встраиваются в
экспорт. Сохраняются времена исходной дорожки; для последнего PGS без команды
исчезновения время окончания требуется задать вручную. Редкие DVD-события
с изменением палитры внутри изображения пока отклоняются с объяснением.

## Точные времена кадров

«Медиа → Точные времена кадров → Прочитать кадры» создаёт индекс реальных
времён показа. Покадровое перемещение и округление к кадрам используют его,
в том числе для VFR. Индекс кэшируется по идентичности видео и автоматически
восстанавливается для того же файла. Чтение можно остановить.
До создания индекса используется выбранная сетка FPS. Индекс не изменяет
медиа и не попадает в субтитровый экспорт. Сам видеоплеер использует декодер Qt;
доставка кадра после перемотки остаётся асинхронной.
