# Локальные автоматические субтитры

Откройте «Файл → Создать субтитры из аудио…», иконку субтитров справа от
видео на верхней панели или действие на пустом экране. Выберите видео/аудио, дорожку,
язык и модель. Кнопка «Скачать» показывает выбранный размер модели;
после загрузки проверяется SHA-256. Модель хранится в `speech-models`
в каталоге данных Substance и удаляется кнопкой «Удалить модель».
Веса не увеличивают размер приложения. После скачивания интернет
для распознавания не нужен; аудио обрабатывается локально.

Модели: Tiny (74 МиБ), Base (141 МиБ), Small (465 МиБ), Medium (1,43 ГиБ)
и Large v3 Turbo (1,51 ГиБ). Все варианты многоязычные. Автоопределение
языка можно заменить явным выбором. На Apple Silicon движок использует
Metal; «Использовать только процессор» отключает GPU.

Диапазон задаётся как `ЧЧ:ММ:СС.мс`; пустой конец означает конец файла.
Тайминги результата учитывают начало выбранного диапазона. Длина строки
настраивается от 20 до 100 символов. Слова объединяются во фразы по
пунктуации, паузам, длительности и вместимости двух строк; перенос
выполняется по пробелам либо символам для CJK.
Музыка, перекрывающиеся голоса, имена и границы реплик требуют проверки.
Перевод и определение персонажей в этот модуль не входят.

Встроенная небольшая модель Silero VAD выделяет речь до распознавания.
Временные метки отдельных слов обрезаются по исходным границам речи,
чтобы последнее слово не растягивалось через удалённую длинную паузу.
В разделе «Тайминг и время чтения» задаются скорость чтения (по умолчанию
17 зн/с), минимальная длительность (1 с), максимальная длина фразы (6 с),
пауза для разделения (450 мс), появление до речи (0 мс), задержка после
речи (120 мс), максимальное продление для чтения (800 мс) и промежуток
между субтитрами (80 мс). Настройки запоминаются после запуска.
Время чтения — целевое: продление ограничивается следующей фразой,
выбранным диапазоном и максимальной задержкой. Быструю речь всё равно
может потребоваться сократить вручную; текст не выбрасывается ради CPS.

Первый результат добавляется в текущий документ либо в новый локальный
документ. При повторном распознавании того же медиа и аудиодорожки
прежние машинные реплики выбранного диапазона обновляются одной операцией
после успешного завершения. Во время повторной обработки старый текст
остаётся виден; при остановке, ошибке или отсутствии речи он сохраняется.
Привязка к медиа и исходное состояние реплик сохраняются в проекте и
сопутствующем файле ASS, поэтому переоткрытие не создаёт новую копию.
Ручные изменения текста, времени, персонажа, разделённые и объединённые
реплики и строки с замечаниями сохраняются; пересекающиеся с ними новые
фразы не добавляются. Реплики на границе выбранного диапазона сохраняются
целиком. Старые результаты без сведений о происхождении защищены от
перезаписи; новые фразы поверх них не создаются. В онлайн-серии добавление
разрешено только для авторского документа: исходник импортированной
серии неизменяем. Для неё доступен новый локальный документ.

После запуска диалог закрывается. В главном окне видны прогресс,
количество распознанных строк и остановка. При первом запуске реплики поступают готовыми
фрагментами; первая порция может потребовать обработки около 30 секунд
аудио, независимо от времени вычислений. Редактор не переключает выбранную
строку и не прокручивает таблицу вслед за результатом. Ручной ввод
в текущей строке сохраняется при поступлении следующих фрагментов.

«Остановить» завершает задачу, сохраняя готовые строки. Обычный Undo
отменяет последовательные машинные порции вместе, но не объединяет их
через ручные изменения или сохранение. «Отменить распознавание» удаляет
нетронутые строки последнего запуска, сохраняя отредактированные строки,
их разделённые/объединённые фрагменты и строки с замечаниями. Эту отмену
также можно отменить обычным Undo.
«Отменить распознавание» после повторного запуска возвращает прежний
машинный результат, сохраняя ручные изменения новых строк. Переключать документ во время задачи
можно после остановки; закрытие окна останавливает задачу и предлагает
сохранить уже полученные строки обычным способом.

## Запуск из исходников и сборка

Нужны CMake и компилятор C/C++ (Xcode Command Line Tools на macOS,
Visual Studio Build Tools на Windows). Выполните:

```sh
python scripts/build_whisper.py
```

Скрипт скачивает исходники whisper.cpp 1.8.3 с проверкой SHA-256,
собирает статический `build/whisper/whisper-cli` (на Windows — `.exe`).
Также скачивается проверенная модель Silero VAD v6.2 (менее 1 МиБ);
она включается в приложение и не требует сети при распознавании.
Metal-библиотека включена в исполняемый файл; сторонние dylib движку
не нужны. `scripts/build.py` вызывает эту подготовку перед упаковкой.
Пользователю готового приложения компилятор и Python не требуются.
Для разработки можно задать путь `SUBSTANCE_WHISPER`.

Модульные проверки: `python -m pytest tests/test_transcription.py -q`.
Реальная проверка с заранее скачанной Tiny и WAV-записью:

```sh
python scripts/transcription_smoke.py --models /path/to/models --media /path/to/speech.wav --cpu --qml
```

Она проверяет поступление строк до окончания задачи, ручную правку
во время работы, сохранение ASS/проекта и выборочную отмену. Результаты
и снимки окна сохраняются в `build/qa/transcription`. Без `--cpu`
проверяется путь с GPU по умолчанию. Этот сценарий ничего не скачивает.
