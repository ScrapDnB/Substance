# Словарь и перевод выделенного текста

В режиме «Перевод» панель под видео показывает значения выделенного слова или перевод выделенной фразы. Можно выделять текст в оригинале и в поле перевода. Соседние реплики остаются в основной таблице. Панель работает и при скрытом видео; её высоту можно менять разделителем.

Все параметры и инструкции находятся в **Настройки → Словарь и перевод**. Кнопка «Настройки…» на панели открывает эту страницу сразу. Показ панели включается в **Настройки → Перевод**.

- Выберите язык оригинала или автоматическое определение и язык переводов/пояснений.
- Слово: начальная форма, части речи, значения, примеры и словарные переводы, если они есть в установленной базе. Формы слова индексируются; статьи с `form_of` дополняются статьёй начальной формы.
- Несколько слов: перевод всего выделенного фрагмента.
- Автопоиск выполняется после паузы 400 мс. Его можно отключить и пользоваться кнопкой «Найти / перевести».
- Результаты можно скопировать. Поиск не меняет документ, оригинал, перевод, ASS-теги или Undo.
- ASS-коды и векторные рисунки не отправляются переводчику. Ответы для прежнего выделения/реплики игнорируются. При скрытии панели запросы отменяются.

## Azure Translator

1. Создайте аккаунт/подписку Azure и ресурс **Translator** в [Azure Portal](https://portal.azure.com/).
2. Выберите **F0**, если требуется бесплатный тариф. На момент реализации опубликован лимит 2 млн символов в месяц; проверяйте текущие условия в [тарифах](https://azure.microsoft.com/en-us/pricing/details/translator/).
3. Откройте **Keys and Endpoint**, скопируйте один из ключей и регион ресурса.
4. Выберите Microsoft Azure в Substance, укажите регион и сохраните ключ. Для глобального ресурса регион можно оставить пустым.
5. Нажмите «Проверить подключение». Проверка переводит приветствие с выбранными языками (по умолчанию `Hello` на русский).

Используется официальный глобальный Text Translation API v3.0 с заголовками `Ocp-Apim-Subscription-Key` и, при наличии региона, `Ocp-Apim-Subscription-Region`. Отдельный пользовательский Azure endpoint пока не предусмотрен. Доступность регистрации зависит от страны и аккаунта. [Официальная инструкция](https://learn.microsoft.com/en-us/azure/ai-services/translator/text-translation/quickstart/rest-api).

## DeepL

Нужен отдельный аккаунт **DeepL API** и ключ из личного кабинета; подписка на веб-переводчик сама по себе API не предоставляет. Сохраните ключ и проверьте подключение. В автоматическом режиме ключ с суффиксом `:fx` использует `api-free.deepl.com`, остальные — `api.deepl.com`. Адрес API можно выбрать вручную. [Аутентификация](https://developers.deepl.com/docs/getting-started/auth), [тарифы](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans).

Опция контекста передаёт DeepL текущую реплику в параметре `context`. Azure и LibreTranslate получают только выделенный фрагмент. Соседние реплики не передаются.

## LibreTranslate

Укажите базовый URL своего сервера, например `http://localhost:5000`, без `/translate` и параметров. Если сервер требует ключ, сохраните его. Ключ привязан к адресу сервера. При смене адреса он не переносится на новый сервер.

С установленным Docker Desktop пример локального запуска для английского и русского:

```sh
docker run -d --name substance-libretranslate -p 127.0.0.1:5000:5000 -e LT_LOAD_ONLY=en,ru libretranslate/libretranslate
```

Дождитесь загрузки моделей и запуска сервера, затем проверьте подключение в Substance. После остановки контейнер можно запустить командой `docker start substance-libretranslate`. Список языков ограничен моделями вашего сервера; для других языков измените `LT_LOAD_ONLY`. Для локального запуска Docker устанавливается отдельно. Установка на VPS автоматизирована мастером ниже. Собственный сервер использует ваши ресурсы; официальный облачный LibreTranslate имеет отдельную оплату. [Установка](https://docs.libretranslate.com/guides/installation/).

### Мастер сервера по SSH

В **Настройки → Словарь и перевод → LibreTranslate → Установка и управление сервером…** доступны установка, подключение существующего контейнера, переустановка и удаление. Пароль SSH, пароль ключа и sudo используются только в памяти. Адрес, пользователь, порт и путь к ключу сохраняются; API-ключ помещается в системное хранилище этого компьютера.

1. Укажите IP/имя SSH-сервера, пользователя, порт, закрытый ключ или пароль. Для SSH-агента оставьте поле ключа пустым. Пользователю без root нужны права sudo; при NOPASSWD пароль sudo оставляется пустым.
2. Укажите домен **уже работающего HTTPS-сайта nginx**. Для сервера Dubbing Manager — его действующий домен. Стандартный nginx include: `/etc/nginx/snippets/dubbing-online.conf`; для другой конфигурации укажите свой подключённый snippet в `/etc/nginx/`.
3. Выберите языки (`en,ru,ja` по умолчанию; en и ru нужны для контрольного перевода). Нужны Linux с Python 3 и минимум 2 ГБ свободного диска; для нескольких языков рекомендуется от 4 ГБ RAM. Если Docker отсутствует, мастер устанавливает системный пакет `docker.io` на Debian/Ubuntu. Создание DNS-записи, HTTPS-сайта и сертификата в этот мастер не входит.
4. Сверьте отпечаток SSH-ключа с консолью/панелью провайдера и подтвердите его. Изменившийся ключ блокирует подключение. Мастер хранит закреплённые ключи отдельно от `~/.ssh/known_hosts`.
5. После проверки сервера выберите действие и подтвердите изменения. До подтверждения контейнеры и nginx не меняются.

Мастер использует контейнер `substance-libretranslate`. Существующий контейнер должен иметь единственную loopback-привязку порта 5000; для новой установки используется `127.0.0.1:15000`. Порт Dubbing Manager 8000 не занимается. Модели и база API-ключей сохраняются в Docker volumes; для моделей внутри записываемого слоя контейнера создаётся снимок образа. Переустановка использует прежнюю версию образа. Остановленная копия старого контейнера остаётся для восстановления.

Через nginx публикуется только защищённый API по адресу `https://ДОМЕН/libretranslate`. Мастер добавляет собственный отмеченный блок в существующий include, проверяет `nginx -t`, контрольный перевод и отказ без API-ключа. После reload nginx проверка HTTPS повторяется в течение минуты: применение конфигурации происходит асинхронно. При постоянной ошибке показывается HTTP-код или причина сбоя TLS/соединения; ответы API и ключи в сообщения не попадают. На сервере Dubbing Manager проверяется его готовность до и после операции. При ошибке восстанавливаются прежний контейнер и nginx, если файл не менялся другим процессом. Рабочие файлы других сервисов и Docker volumes не удаляются.

После успешной установки адрес и сгенерированный API-ключ автоматически добавляются в настройки Substance. При недоступном системном хранилище приложение сообщает, что ключ остался только в памяти.

Удаление останавливает сервис и убирает его маршрут HTTPS; языковые модели, база ключей и остановленная копия контейнера сохраняются. Удалять через мастер можно только сервис с отмеченным блоком Substance. Полная очистка резервных копий/томов намеренно отсутствует.

Операция запускается отдельным процессом на сервере и продолжает работу при закрытии окна или обрыве SSH. Номер и точный запрос без секретов сохраняются на компьютере; при повторном открытии мастера подключитесь снова для проверки результата. Неизвестный результат повторяется с тем же UUID. После перезапуска ОС сервера или принудительного завершения процесса мастер показывает ошибку и путь к копиям для восстановления. Состояние и копии доступны root в `/var/lib/substance-libretranslate/НОМЕР_ОПЕРАЦИИ/`; API-ключ находится только в приватном `result.json`.

Для прежней ручной схемы остаётся `scripts/configure_libretranslate_https.py`. Новый мастер использует отдельный поставляемый runtime `substance/resources/libretranslate_server.py`, поэтому Python-библиотеки Substance на VPS не требуются.

## Локальные словари

Кнопки на странице настроек скачивают и индексируют реальные данные [Kaikki / Wiktextract](https://kaikki.org/dictionary/rawdata.html):

- **Базовый английский** — редакция Simple English, примерно 5 МБ загрузки, общеупотребительная лексика с английскими пояснениями.
- **Русская редакция** — примерно 295 МБ загрузки, статьи о словах разных языков с русскими пояснениями.

Размеры меняются у источника. Индекс занимает дополнительное место. Для полных баз другой редакции скачайте raw `JSONL` или `JSONL.GZ` из каталога Kaikki, выберите **язык пояснений редакции** и импортируйте файл. В английской редакции пояснения на английском даже у японских или русских слов. Не выбирайте язык самих слов вместо языка редакции.

Индексирование происходит в фоне; доступны прогресс и отмена. Обновление заменяет только полностью готовую базу, при ошибке/отмене прежняя сохраняется. Словари и настройки хранятся на этом компьютере, отдельно от `.substance`, ASS и онлайн-серии.

Значения и примеры из установленных баз работают без сети и ключей. Источник и ссылка на статью показаны рядом с результатом. Словарные переводы зависят от полноты исходных статей. Если язык пояснений отличается от выбранного, можно включить их машинный перевод: он отдельно обозначается, оригинал остаётся видимым. Автоматически переводится ограниченная первая страница значений; это тоже расходует квоту сервиса.

## Ключи, ошибки и проверка

Ключи сохраняются в macOS Keychain / Windows Credential Manager / Linux Secret Service и не записываются в настройки или документ. Если системное хранилище недоступно, ключ работает до закрытия Substance; об этом появляется сообщение. Нет общего встроенного ключа разработчика.

Сетевые ошибки, неверный ключ и исчерпание квоты показываются на панели; локальные значения остаются доступными. Платный сервис не включается автоматически. Результаты кешируются только в памяти (до 64 выделений), с учётом текста, контекста, языков и сервиса; смена ключа/настроек очищает кеш.

Автотесты проверяют контракты трёх API, Unicode/ASS-выделение, словарные формы и примеры, атомарный импорт, устаревшие ответы, отсутствие ключей в INI, инструкции и реальные QML-выделения. Проверка с вашим API-ключом и доступность конкретного сервера выполняются кнопкой подключения.

## Только локальные словари

Флажок **«Только локальные словари»** отключает запросы к Azure, DeepL и LibreTranslate, включая проверку подключения и перевод пояснений. Названия сервисов, их настройки и инструкции скрываются; панель показывает словарные значения, примеры и переводы из локальных статей. Для предложения появляется подсказка выделить одно слово. Текущий ответ переводчика сбрасывается; уже отправленный запрос отменить на стороне сервиса невозможно, но его ответ не отображается и следующие запросы не отправляются.

Настройки и ключи сервисов сохраняются, поэтому после снятия флажка не нужно вводить их заново. Скачивание нового словаря и открытие источника остаются отдельными явными действиями пользователя. Режим не останавливает уже установленный на VPS сервер; для этого служит удаление в мастере.
