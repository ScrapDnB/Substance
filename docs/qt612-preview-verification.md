# QML Live Preview: проверка 18 октября 2026

## Результат

Предпросмотр работает через установленный
`~/Qt/6.12.0/macos/bin/QmlPreviewMcpServer` и отдельное окружение `.venv-qt612`.
Файл `QML Preview.command` запускает приложение и завершает сервер после
закрытия окна. Обычное окружение `.venv` и зависимость в `pyproject.toml`
остались на PySide6 6.10.2.

Полный перевод релизного пакета на 6.12.0 отклонён проверкой Mach-O:
Qt frameworks требуют macOS 14.4, но проверенные Python-биндинги
`QtCore.abi3.so`, `libpyside6.abi3.6.12.dylib` и `Shiboken.abi3.so`
объявляют минимум macOS 26.0. Метка wheel `macosx_14_0` не отражает этот
фактический минимум. Кроме того, локальный Homebrew Python 3.14 сам требует 26.0;
он подходит для предпросмотра на этом компьютере, но не для пакета macOS 15.

Отдельный релизный пакет собран через существующий `.venv-build` на Python 3.12
и Qt 6.10.2. Все 504 включённых Mach-O имеют минимум не выше macOS 15.
Проверочный пакет находится в `dist-preview-compatible/Substance.app`.
Отклонённый пакет Qt 6.12 удалён; диагностика сохранена в
`build/qa/qt612-preview/compatibility.json`.

## Выполненные проверки

- Настоящий MCP вызов `run_qmlPreview`: в копии рабочего `Main.qml` свойство
  изменено с 1 на 2. Значение изменилось в существующем окне; его C++ адрес
  остался прежним. Результат и проверенный снимок:
  `build/qa/qt612-preview/result.json`, `hot-reload.png` в той же папке.
- 50 нативных проверок macOS на Qt 6.12, включая NSToolbar, Liquid Glass,
  меню, горячие клавиши и подсказки. Исправлена обнаруженная регрессия:
  нативные tooltip regions теперь следуют сигналам геометрии предков и
  не зависят исключительно от `afterAnimating`.
- Полный запуск тестов на Qt 6.12: 457 пройдено, 4 пропущено; один сценарий
  закрытия превысил 15 секунд на первом запуске. Оба сценария закрытия
  отдельно повторены без параллельной сборки: 2 пройдено за 5.17 секунды.
- После полного отделения preview-окружения: 18 проверок медиаплеера,
  аудиоконтролов, подсказок и режима debugging пройдено. В окружении
  отсутствуют ссылки на пакеты обычной `.venv`; `pip check` проходит.
- На обычной Qt 6.10.2: 22 проверки управления, подсказок, режима preview
  и горячих клавиш пройдено; 1 платформенная проверка пропущена.
- `QML Preview.command -- --smoke-test --diagnostics ...` завершился с кодом 0;
  диагностика подтвердила `qtVersion: 6.12.0`, `qmlPreview: true`.
- Пакет запущен из временной папки без исходников и сборочных переопределений:
  QML, платформенный стиль, FFmpeg, ffprobe, libass, Whisper и VAD проверены.
  В пакете `qtVersion: 6.10.2`, `qmlPreview: false`; явный запрос
  `--qml-preview` отклонён. Отчёты: `build/qa/ci-package.json` и
  `build/qa/macos-minimum.json`.

Проверки выполнены на текущем Mac. Запуск на физической macOS 15 и Windows
в этой работе не выполнялся; проверка минимальных версий Mach-O не заменяет
такой запуск. Приложение в Applications и опубликованные релизы не заменялись.

## Повторение

```sh
.venv/bin/python scripts/setup_qml_preview.py
.venv-qt612/bin/python scripts/qml_preview.py --check
.venv-qt612/bin/python scripts/qml_preview.py
QT_QPA_PLATFORM=cocoa .venv-qt612/bin/python scripts/qml_preview_smoke.py
```

Предпросмотр использует отдельные настройки `local/qml-preview-state`.
Изменения QML сохраняются в исходниках; при открытии своего документа
предпросмотр работает с настоящим документом, поэтому обычное сохранение
продолжает записывать его на диск.
