## Повторение

```sh
.venv/bin/python -m pytest -q tests/test_file_workflows.py tests/test_acoustic_timing.py tests/test_bitmap_formats.py
.venv/bin/python -m pytest -q tests/test_editor_tools_ui.py tests/test_timing_ui.py tests/test_workflow_ui.py
QT_QPA_PLATFORM=cocoa QSG_RENDER_LOOP=basic SUBSTANCE_TEST_STYLE=macOS \
  SUBSTANCE_WORKFLOW_SCREENSHOTS=build/qa/workflows \
  .venv/bin/python -m pytest -q tests/test_workflow_ui.py
```

Нативный прогон требует доступа к рабочему столу macOS. SSH-тесту нужен
локальный сокет. `test_bitmap_formats.py` использует установленный PyAV.
Windows проверен тестами интерфейса исходников; настоящий Windows-прогон
новых функций и новая сборка `.app`/`.exe` в эту проверку не входят.
Для акустической точности на длинных реальных материалах нужны дополнительные
контрольные записи; успешный короткий тест не заменяет такую оценку.
