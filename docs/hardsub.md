# Поиск и распознавание хардсаба

Команда **Инструменты → Найти и распознать хардсаб…** доступна и без готового
документа субтитров. В панели видео есть кнопка **Хардсаб…**.

1. Откройте видео. На нужной позиции получите кадр кнопкой **Кадр с текущей позиции**.
2. Выделите область текста мышью на кадре. Есть готовые области: нижняя часть,
   верхняя часть и весь кадр. Координаты и размеры можно уточнить в процентах.
3. Выберите язык и диапазон времени. Запустите **Найти и распознать**.
4. Проверьте найденные фрагменты, снимите галочки с вывесок, логотипов и титров.
   Внизу списка показан кадр с текстом выбранного фрагмента. Текст и таймкоды
   можно исправить; правки сохраняются кнопкой и при выборе другого фрагмента.
5. Нажмите **Добавить выбранное**. Для перевода включите соответствующую галочку:
   OCR-текст станет оригиналом, поле перевода останется пустым, откроется режим перевода.

Документ меняется только при добавлении; весь импорт отменяется одним действием.
Существующие реплики сохраняются. Совпадающий текст с пересекающимся временем
пропускается при повторном импорте. Результат нельзя применить после изменения
документа или видео. В онлайн-серии с неизменяемым оригиналом добавление запрещено;
для такого импорта используйте локальный документ.

## Движки

На macOS используется системный **Apple Vision** через PyObjC. Для запуска из
исходников обновите зависимости проекта обычной установкой из `pyproject.toml`.
Пакеты Vision, Quartz и CoreML включены в зависимости для macOS и настройки сборки.
Доступные языки запрашиваются у ОС, включая русский и японский, если их поддерживает
установленная версия Vision. Видео не отправляется в облако.

На Windows/Linux используется установленный отдельно **Tesseract** с языковыми
пакетами. Движок ищется в PATH, типичных каталогах установки, переменной
`SUBSTANCE_TESSERACT`; исполняемый файл можно выбрать кнопкой **Tesseract…**.
Кнопка **Авто** возвращает автоматический выбор движка. Список языков содержит
только установленные модели: например, `eng`, `rus`, `jpn`, `chi_sim`.
Tesseract и его языковые модели в сборку Substance не входят.

Документация движков: [Apple Vision](https://developer.apple.com/documentation/vision/vnrecognizetextrequest),
[установка Tesseract](https://tesseract-ocr.github.io/tessdoc/Installation.html),
[языковые данные](https://tesseract-ocr.github.io/tessdoc/Data-Files.html).

## Точность и ограничения

Это поиск устойчивого текста в выбранной области, а не семантическая классификация
хардсаба: вывески, титры, караоке и логотипы тоже могут распознаться.
Сложные шрифты, движущийся фон и вертикальный текст требуют ручной проверки.
Одновременно видимый текст внутри области объединяется в один фрагмент.

Кадры декодирует FFmpeg без наложения открытых в редакторе субтитров и без
подключения встроенных мягких субтитров. При стандартном шаге 250 мс проверяются
четыре кадра в секунду; границы реплик приблизительные с точностью до шага.
Текст, появившийся между проверяемыми кадрами, может быть пропущен. Фрагменты короче
заданного минимума отбрасываются. Уменьшение шага повышает временную точность и
увеличивает время работы. Пустой результат означает только отсутствие распознанного
текста при этих настройках, а не доказанное отсутствие хардсаба.

Проверка без системных OCR-служб:

```sh
.venv/bin/python -m pytest tests/test_hardsub.py tests/test_hardsub_ui.py -q
```

Полный тест Apple Vision на синтетическом видео (macOS, доступ к системным службам):

```sh
SUBSTANCE_TEST_VISION=1 .venv/bin/python -m pytest tests/test_hardsub.py -k native_vision -q
```
